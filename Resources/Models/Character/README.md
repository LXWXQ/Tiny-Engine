- 文件：`Character.glb`
- 来源：Quaternius，Platformer Game Pack
  - 资产页：https://quaternius.com/packs/platformergame.html
  - 展示/下载页：https://quaternius.com/
- 许可：CC0 1.0 Universal（公共领域，可商用，无需署名；这里保留来源说明便于追溯）
  - https://quaternius.com/license.html
- 内容：4 个蒙皮网格、29 根骨骼、18 个动画；运行时使用 Idle / Walk / Run / Jump / Jump_Idle / Jump_Land。
